用法:
  {{exe}} <source-dir> [dest-name] [--restart|--rebuild] [--analyze] [--container <name-or-id>] [--repos <path>] [--registry <path>]

选项:
  -h, --help      显示帮助信息
  --restart       写入 repos.json 后执行容器重建
  --rebuild       --restart 的别名
  --analyze       写入后重建容器，并对新增 repo 执行 analyze
  -c, --container 指定要重建/分析的容器；未指定时走交互选择
  --repos         指定要写入的 repos.json 路径；未指定时可从容器 label 推断
  --registry      指定后续 start 使用的 registry.json 路径；未指定时可从容器 label 推断
