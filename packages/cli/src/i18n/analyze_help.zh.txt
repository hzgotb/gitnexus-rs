用法:
  {{exe}} [--container <name-or-id>] [--registry <path>] [--repo <repo_name> | --all] [--jobs <n>] [--] [analyze_args...]

选项:
  -h, --help       显示帮助信息
  -c, --container  指定目标运行容器
  --registry       指定 registry.json 路径；未指定时优先读取容器绑定的 json 组
  -r, --repo       指定容器内 /repos 下的目标仓库
  -a, --all        对 /repos 下所有仓库执行 analyze
  -j, --jobs       --all 模式并发数（默认: 1）

示例:
  {{exe}}                         # 交互选择容器/仓库
  {{exe}} --registry ./registry-a.json
  {{exe}} --all                   # 对所有仓库执行 analyze
  {{exe}} --all -j 4              # 4 并发执行
  {{exe}} -c gitnexus-abcd1234    # 指定容器并选择仓库
  {{exe}} -c gitnexus-abcd1234 -r vue -- --format json
  {{exe}} -c gitnexus-abcd1234 --all -- --format json
