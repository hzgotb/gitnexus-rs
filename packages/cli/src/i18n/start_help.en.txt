Usage:
  {{exe}} [--tag <tag>] [--port <port>] [--registry <path>] [--repos <path>] [--rebuild <name-or-id>]

Options:
  -h, --help      Show this help message
  -t, --tag       Override image tag (default: latest)

  -r, --registry  Override registry.json path (absolute or relative)
  --repos         Override repos.json path (absolute or relative)
  --rebuild       Rebuild the specified existing container directly
